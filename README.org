* How does this work?

I like writing all my documentation and blog posts in the amazing Org mode, from within Emacs.
I also use Emacs to generate HTML from these files, which I then host online.

This is an Emacs Lisp tool to build and publish the [[https://jointhefreeworld.org][https://jointhefreeworld.org]] website using Org-mode publishing.

It leverages a custom HTML export backend to convert Org files into a fully styled static site with dynamic content features.


*Custom HTML Export*:
  Uses a derived `site-html` backend to generate pages with custom headers, footers, and layout.

*Multi-Project Publishing*:
  Organizes content into multiple projects (e.g., home, blog, documentation, portfolio) via `org-publish-project-alist`.

*RSS Feed Generation*:
  Integrates with `webfeeder` to build an RSS feed for news and insights.

* Using

You will need:

- *Emacs 29.1 or newer*
- *Git* (for version control and commit hash extraction)

The script at ~./jointhefreeworld-site.el~ automatically sets up a local package directory and installs the required packages:
   - ~esxml~
   - ~htmlize~
   - ~webfeeder~

These are fetched from MELPA and MELPA Stable.

Publish the entire site by running:

#+begin_src sh
  emacs -Q --batch -l ./jointhefreeworld-site.el --funcall jfw/publish
#+end_src


* Configuration

The ~org-publish-project-alist~ variable defines various projects (e.g., home, blog, documentation, portfolio). Modify these entries to suit your directory structure.

Functions like ~jfw/site-header~, ~jfw/site-footer~, and ~jfw/generate-page~ can be adjusted to change the look and feel of the generated site.

* On Reproducibility: Why GNU Guix?

A build should never fail because "it worked on my machine." Reliable software development requires explicit, bit-for-bit reproducibility and a functional approach to package management and system deployment.

#+BEGIN_EXPORT html
<a href="https://guix.gnu.org/">
  <img src="https://jointhefreeworld.org/ggg/dist/gnu-guix.svg" alt="GNU Guix logo" style="max-width: 250px; width: 100%; height: auto;" />
</a>
#+END_EXPORT

- *Declarative Build Graphs:* Packages are pure functions of their inputs with no implicit system state.
- *Programmable with Guile:* Full system and package configurations written in [[https://www.gnu.org/software/guile/][Guile Scheme]] rather than rigid DSLs or static files.
- *Time Travel:* Rebuild the exact system state from any point in git history using ~guix time-machine~.
- *Atomic Operations:* Instantly upgrade or roll back environments without leaving orphaned dependencies or broken states.
- *Unified Tooling:* One tool manages development shells, isolated containers, package builds, and full system configurations.
