* The rings

- Adopt :: proven in daily work, and the default for anything new.
- Trial :: running on real projects, not yet a default.
- Assess :: worth a prototype, and no commitment yet.
- Deprecate :: actively discouraged for new work.

A name in parentheses — ~(new)~, ~(moved in)~, ~(moved out)~ — says what changed
since the last revision; a note after a dash says why.

* What FREE means

- F — Functional :: declarative, predictable systems with clear effects.
- R — REPL :: code evaluated on the running system, with no write-compile-test lag.
- E — Extensible :: a stack built to scale into flexible, extensible systems.
- E — Environment Control :: the whole lifecycle under my own control: no hidden telemetry, no paywalls, one-command self-hosting.
