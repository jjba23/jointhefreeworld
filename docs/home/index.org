I build all kinds of tech solutions for the day-to-day problems of my clients and of myself. See [[file:../blog/articles/development/tech-radar/][The FREE stack - My Tech Radar]].

The jointhefreeworld project has an [[../blog/articles/personal/jointhefreeworld-code-of-conduct/index.html][inclusive and community-driven code of conduct]].

For development convenience in the jointhefreeworld platform, we keep [[../platform/ports/index.html][an overview of reserved ports]] for a [[https://codeberg.org/jjba23/wolk-jjba][VPS / server]].

I also maintain a [[/blog/articles/personal/jointhefreeworld-documentation-style-guide/index.html][style guide for documentation]] to help you write better documentation, manuals, tutorials, and READMEs.

💼 For free and open source project management, check the [[https://lucidplan.jointhefreeworld.org][LucidPlan project]], a good alternative to commercial planning tools like Trello or Jira.

⚙️ For CI/CD with a Lisp/Scheme flavour, free as in freedom, check the [[https://byggsteg.jointhefreeworld.org][Byggsteg project]]. Let's get you set up with Lispy server infrastructure for continuous integration that is easy and flexible.

🎻 If you play an instrument, want to learn music, or share musical knowledge, check the [[https://wikimusic.jointhefreeworld.org][WikiMusic project]], dedicated to sharing musical knowledge and exploring music freely.

I also [[https://www.youtube.com/channel/UCdIkk-5jPA2HaAEB5a5X6XA][make videos]] about music, guitar 🎸, Lisp, GNU Guix, Nix, Haskell, and more.
