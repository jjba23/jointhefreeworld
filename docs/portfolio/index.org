Hello there! You have landed on the portfolio of Josep Jesus Bigorra Algaba, a passionate advocate for free software 👋🏼

Below you will find a collection of my projects, ranging from deep system customization and web-server engineering and orchestration to developer tools and elegant Emacs enhancements 🪄

Take a look around, and feel free to explore the code and the ideas behind each one!

[[https://codeberg.org/jjba23/wikimusic][WikiMusic]] - A free music-knowledge encyclopaedia.
