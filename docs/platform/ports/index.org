This document outlines the ports commonly reserved on the GNU/Linux-based virtual servers (VPS) used by the jointhefreeworld project and the wolk-jjba VPS configuration. Understanding them matters because:

   - They relate to system security.
   - Services may require specific ports to function properly.
   - When you develop a service, you can tell which ports are still free to use.

* Custom ports

Note that some of the ports below are not always in use on a production VPS, since a few are used only for local development.

* System-specific port usage

- SSH server :: we commonly move this to port 2323
- HTTP/HTTPS web servers :: we keep the default ports 80 and 443, and reverse proxy (with NGINX) from there
